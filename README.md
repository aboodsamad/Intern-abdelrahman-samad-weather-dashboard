Weather App

A simple weather app I built with React and TypeScript. You type a city name and it shows the current weather and the forecast for the next 5 days. The weather data comes from the OpenWeatherMap API. I made it to practice the Fetch API, async programming, working with an API, and error handling.

Features

Search for any city.
Shows the current temperature, condition and humidity.
Shows a 5 day forecast.
Shows a loading spinner while the data is loading.
Shows an error message if the input is empty, the city is not found, or the request fails.
The background color changes depending on the weather.

Built with

React, TypeScript, Vite, react-spinners and the OpenWeatherMap API.

Installation

You need Node.js and npm installed.
Clone the repo with git clone https://github.com/aboodsamad/Intern-abdelrahman-samad-weather-dashboard.
Instll the packages by running npm install.
Get a free API key from https://openweathermap.org
Create a file called .env in the root of the project and put in it the API Key.
Start the app by running npm run dev.
Open the link that shows up in the terminal, usually http://localhost:5173
